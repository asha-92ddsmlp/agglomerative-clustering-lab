Step-by-Step Hierarchical Clustering (8 sample points)

This teaching demo shows how clusters merge one pair at a time. It is a small illustrative dataset, separate from the 200-customer dataset above.

Step 0 of 7

Methodology

  1. Use Annual Income and Spending Score as the two clustering features.
  2. Calculate pairwise distances and merge the closest clusters according to the selected linkage rule.
  3. Cut the resulting hierarchy to obtain the selected number of clusters.
  4. Compare the result using cluster profiles, cluster sizes, scatter plots, and the silhouette score.

Note: This is a browser-based educational implementation. Small differences from Python/scikit-learn may occur because implementation details and distance/update rules can differ. For formal numerical results, use the accompanying Colab notebook as the primary analysis.
